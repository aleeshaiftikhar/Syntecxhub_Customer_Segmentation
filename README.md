# Customer Segmentation Using K-Means

## Project Overview
This project uses K-Means clustering to group mall customers based on their age, annual income, and spending score. The goal is to identify customer segments that can help businesses develop targeted marketing strategies.

## Dataset
- Dataset: Mall Customers
- Total Records: 200
- Features: Age, Annual Income, Spending Score

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Methodology
1. Loaded and explored the customer dataset.
2. Selected relevant features for clustering.
3. Applied the Elbow Method to help determine the number of clusters.
4. Applied K-Means clustering with five clusters.
5. Visualized the customer segments.
6. Analyzed each cluster and prepared marketing recommendations.

## Results
The model identified five customer segments with different age, income, and spending patterns. The analysis can help businesses understand customer behavior and plan suitable marketing campaigns.

## Conclusion
K-Means clustering provides a useful way to segment customers and develop marketing strategies based on their characteristics and spending behavior.
